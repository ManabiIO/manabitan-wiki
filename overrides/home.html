Yomitan, with less waiting and less setup.

Keep the familiar lookup, audio, dictionary, and Anki workflow, with faster imports and lookups, dramatically smaller installed dictionaries, and less manual setup.

Install Manabitan Why use Manabitan?

Manabitan is a separate project with substantial internal changes. If you are moving from Yomitan, keep a backup and follow the migration guide.

Why use Manabitan instead of Yomitan?

The storage rewrite is the foundation, not the whole product pitch. Manabitan also removes setup and maintenance work around the same reading workflow.

Faster imports and lookups

Spend less time waiting for dictionaries to import and for definitions to appear, especially with large collections or constrained devices.

Why performance matters

Dramatically less disk space

Imported dictionaries take up dramatically less space than in Yomitan. This is a smaller installed footprint, not just a smaller download, making large collections more practical.

Installed storage savings

Update while you keep reading

Installed dictionaries can stay available while new data is prepared. Dictionaries with web update sources can check on hourly, daily, weekly, or monthly schedules.

Dictionary updates

Anki fields that configure themselves

Already use Kiku, Lapis, Senren/洗練, or Crop Theft Vocab? Select the existing note type and Manabitan fills its expected field markers. Package-based tests check the presets against upstream field layouts.

Automatic Anki mapping

More dictionary options

Use Yomitan-format dictionaries or import MDX, install recommended dictionaries together, edit supported metadata, and use bulk update actions.

Reading quality of life

Built-in popup themes and frequency-based recall blur add options around the existing lookup workflow without asking you to learn a different product.

Appearance and advanced features

Where Manabitan is headed

Nothing is set in stone. The general directions are continued maintenance and upstream Yomitan improvements, easier onboarding, faster imports and lookups, lower memory and storage use, and a much faster, more capable AnkiConnect integration. We also intend to improve AnkiConnect itself rather than forcing every limitation to be solved inside Manabitan.

We are developing a public benchmark suite comparing imports, lookups, and storage across tools compatible with Yomitan dictionaries. We have no current plans for dramatic changes to Yomitan's general functionality, design, or familiar behaviors.

Read the roadmap

Why is Manabitan a fork?

The storage and query rewrite is large enough that building it, reviewing it incrementally upstream, and safely migrating Yomitan's entire installed base are separate projects. Yomitan's primary maintainers have supported releasing this work as a fork, offered guidance, and reviewed our release preparations. Manabitan is maintained and released independently.
