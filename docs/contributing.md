# Contributing

For extension code, read [Manabitan's contributing guide](https://github.com/ManabiIO/manabitan/blob/main/CONTRIBUTING.md). Discuss substantial changes in the [Manabi Discord](https://discord.gg/gvxzS93C3w) before starting so the work can be coordinated. Do not depend on an Issues form while Issues are disabled.

## Documentation changes

This site lives in [ManabiIO/manabitan-wiki](https://github.com/ManabiIO/manabitan-wiki), not the extension repository. Submit documentation pull requests there. The repository README explains local preview and validation. The page edit control also points to the wiki repository.

Use the actual control labels in the supported build. Distinguish source inspection from a released-package test. Do not claim platform support, automatic updates, benchmark ratios, or backup interoperability without the relevant evidence.

Keep upstream and third-party names where they identify a real project, protocol, format, or contributor. Update Manabitan branding without erasing attribution. For a screenshot or demonstration, record the build, browser, and platform, remove personal data, and avoid presenting upstream UI as a current Manabitan capture.

## Useful reports

Reproducible import/lookup problems, compatibility results on constrained devices, accessible documentation, language improvements, and focused tests are useful contributions. See [Tech support](support.md#reporting-a-problem) for what to include in a report.
